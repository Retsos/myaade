POST /api/sendInvoice — Τι κάνει ο server σου

Αυτό είναι το endpoint που εκθέτεις εσύ

1

Παραλαμβάνει minimal request

Δέχεσαι customer_id, στοιχεία τιμολογίου (ποσά, τύπος), χωρίς issuer χωρίς counterpart details.

2

Ανάκτηση από DB

SELECT από company → issuer fields. SELECT από customers WHERE id = customer_id → counterpart fields.

3

Κατασκευή πλήρους JSON

Συνδυάζεις issuer + counterpart + invoice data → φτιάχνεις το payload που περιμένει η etimologiera.

4

POST → etimologiera /sendSimInvoice

Στέλνεις με Basic Auth. Περιμένεις απάντηση.

5

Επιστρέφεις mark + invoiceUrl

Αν πήγε καλά → επιστρέφεις { mark, invoiceUrl }. Αν 701/702 → offline fallback.
